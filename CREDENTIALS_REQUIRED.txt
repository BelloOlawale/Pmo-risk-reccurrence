TIER 1 — NEEDED NOW (embeddings seed + pgvector search + LLM suggestions)
================================================================================

--- 1. Azure OpenAI (embeddings + chat) ---------------------------------------

RISKAPP_AZURE_OPENAI_ENDPOINT
    Azure OpenAI resource endpoint, e.g. https://<resource>.openai.azure.com/

RISKAPP_AZURE_OPENAI_API_KEY
    One of the two API keys from the Azure OpenAI resource.

RISKAPP_AZURE_OPENAI_EMBEDDING_DEPLOYMENT
    Deployment name of the text-embedding-3-small model.
    (default fallback: text-embedding-3-small)

RISKAPP_AZURE_OPENAI_CHAT_DEPLOYMENT
    Deployment name of the GPT-4o-mini model (for LLM suggestions, issue #06).

RISKAPP_AZURE_OPENAI_API_VERSION
    Azure OpenAI API version, e.g. 2024-02-01 (default).
    Note if your region requires a different version.

--- 2. PostgreSQL + pgvector (real DB, migrations, native cosine search) -------

RISKAPP_DATABASE_URL
    Full SQLAlchemy connection string, e.g.:
        postgresql+psycopg://user:password@host:5432/dbname?sslmode=require
    Components needed (or a full connection string):
        - host
        - port (usually 5432)
        - database name
        - username
        - password
    Requirement: the server must have the pgvector extension available
    (Azure Database for PostgreSQL Flexible Server does). The migration runs
    CREATE EXTENSION IF NOT EXISTS vector automatically.
